📦 food-ordering-app

A modern Food Ordering Web Application built using React, Parcel, and Tailwind CSS.
This project demonstrates core React concepts such as components, routing, state management, hooks, and reusable UI design.

🚀 Features

🍽️ Browse restaurants and food items

📂 Category-wise menu display

🛒 Add items to cart

🔄 Dynamic cart item count

🌙 Dark / Light mode toggle

⚡ Fast build using Parcel

🎨 Responsive UI with Tailwind CSS

🛠️ Tech Stack

Frontend: React JS

Bundler: Parcel

Styling: Tailwind CSS

Routing: React Router

State Management: React Hooks

Version Control: Git & GitHub

⚙️ Installation & Setup

### Frontend Setup
```bash
cd frontend
npm install
npm start
```

### Backend Setup
```bash
cd backend
npm install
npm run dev
```
